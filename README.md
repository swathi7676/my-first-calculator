# My First Calculator

A simple calculator that runs in a web browser.

## What it can do

- Add, subtract, multiply, and divide
- Enter decimal numbers
- Clear the display
- Delete the last digit

## How to use it

Open the calculator here: https://swathi7676.github.io/my-first-calculator/

Click the number buttons and an operation button, then press `=` to see the answer. Press `C` to clear.

## Built with

- HTML for the calculator buttons and display
- CSS for the design
- JavaScript for the calculations

The app is in `index.html` and is published using GitHub Pages.
